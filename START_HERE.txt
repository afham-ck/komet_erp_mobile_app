🎯 CORE FEATURES:
═════════════════════════════════════════════════════════════════════════════

  1. CUSTOMER LIST
     → Searchable, sorted by balance (highest first)
     → Tap to view ledger

  2. CUSTOMER LEDGER
     → Invoice history with dates, amounts, balances
     → RED "OVERDUE" badge for unpaid 30+ day invoices
     → BIG "Collect Payment" button

  3. QUICK PAYMENT
     → Simple form: Amount + Mode (Cash/UPI/Card) + Note
     → One-tap confirmation
     → Works offline (saves locally, syncs when online)

  4. ADD CUSTOMER
     → Mandatory: Name, Phone
     → Collapsible: Email, Address (optional)
